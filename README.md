## Deskripsi

Repository ini berisi source code hasil pengerjaan Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web Dasar. Aplikasi yang dikembangkan bernama **CarFit – Pilih Mobil Sesuai Kemampuan**.

## Deskripsi Pengerjaan UTS

CarFit merupakan aplikasi web yang membantu pengguna mempertimbangkan kemampuan finansial sebelum membeli mobil. Analisis dilakukan berdasarkan pendapatan, pengeluaran rutin, cicilan yang sedang berjalan, tabungan, serta estimasi biaya pembelian dan kepemilikan mobil.

Aplikasi menggunakan pendekatan berbasis aturan (*rule-based*) untuk menghasilkan rekomendasi kelayakan pembelian mobil. Hasil analisis dibagi menjadi tiga kategori: Sesuai, Perlu Pertimbangan, dan Belum Sesuai.

Aplikasi dikembangkan menggunakan HTML, CSS, dan JavaScript dengan penyimpanan data pada browser melalui localStorage.

## Fitur yang Diimplementasikan

1. Halaman utama CarFit.
2. Autentikasi pengguna.
3. Katalog dan detail mobil.
4. Profil dan data keuangan pengguna.
5. Analisis kemampuan finansial.
6. Rekomendasi mobil berdasarkan kemampuan finansial.
7. Hasil dan riwayat analisis.
8. Halaman admin untuk pengelolaan data mobil pada sisi frontend.

## Struktur Folder

- `index.html`: Halaman utama aplikasi.
- `auth.html`: Halaman autentikasi.
- `catalog.html`: Halaman katalog mobil.
- `detail.html`: Halaman detail mobil.
- `dashboard.html`: Halaman dashboard pengguna.
- `profile.html`: Halaman profil pengguna.
- `analysis.html`: Halaman analisis finansial.
- `recommendations.html`: Halaman rekomendasi mobil.
- `result.html`: Halaman hasil analisis.
- `history.html`: Halaman riwayat analisis.
- `admin.html`: Halaman admin.
- `css/`: File stylesheet.
- `js/`: File JavaScript.

## Cara Menjalankan Aplikasi

1. Unduh atau clone repository dari GitHub.
2. Buka folder proyek `carfit-uts`.
3. Buka file `index.html` menggunakan browser.
4. Alternatifnya, buka folder proyek menggunakan Visual Studio Code dan jalankan dengan ekstensi Live Server.

Versi ini berfokus pada frontend dan tidak memerlukan PHP atau database server untuk dijalankan.
