## Deskripsi

Repository ini berisi source code dan dokumentasi hasil pengerjaan Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web Dasar.

Aplikasi yang dikembangkan adalah **CarFit – Pilih Mobil Sesuai Kemampuan**, yaitu aplikasi berbasis web yang membantu pengguna mengetahui kesesuaian kemampuan finansial dalam membeli dan memiliki mobil berdasarkan kondisi keuangan serta estimasi biaya kendaraan.

## Deskripsi Pengerjaan UTS

CarFit merupakan aplikasi web yang dirancang untuk membantu pengguna mempertimbangkan kemampuan finansial sebelum membeli mobil. Aplikasi ini menggunakan pendekatan perhitungan berbasis aturan (*rule-based*) untuk menganalisis kesesuaian kendaraan berdasarkan pendapatan, pengeluaran rutin, cicilan lain, tabungan, serta estimasi biaya pembelian dan kepemilikan kendaraan.

Perhitungan mencakup biaya awal pembelian, uang muka, cicilan kendaraan, biaya energi, pajak, servis, dan cadangan biaya perbaikan. Hasil analisis digunakan untuk memberikan gambaran tingkat kesesuaian kendaraan dengan kemampuan finansial pengguna.

Aplikasi dikembangkan menggunakan HTML, CSS, dan JavaScript dengan penyimpanan data menggunakan Local Storage pada browser.

## Fitur yang Diimplementasikan

1. **Katalog Mobil:** Menampilkan daftar kendaraan beserta informasi dan spesifikasinya.
2. **Detail Mobil:** Menampilkan informasi lebih lengkap mengenai kendaraan yang dipilih.
3. **Analisis Kemampuan Finansial:** Menghitung kemampuan pengguna berdasarkan pendapatan, pengeluaran, cicilan, dan tabungan.
4. **Simulasi Pembelian Mobil:** Menghitung estimasi uang muka, cicilan, tenor, dan biaya awal pembelian.
5. **Estimasi Biaya Kepemilikan:** Menghitung estimasi biaya energi, pajak, servis, dan cadangan perbaikan.
6. **Hasil Analisis:** Menampilkan status kesesuaian kendaraan berdasarkan hasil perhitungan finansial.
7. **Rekomendasi Mobil:** Memberikan rekomendasi kendaraan berdasarkan hasil analisis kemampuan finansial.
8. **Autentikasi Pengguna:** Menyediakan fitur registrasi dan login.
9. **Dashboard Pengguna:** Menampilkan ringkasan informasi dan aktivitas pengguna.
10. **Riwayat Analisis:** Menyimpan dan menampilkan hasil analisis sebelumnya.
11. **Manajemen Profil:** Memungkinkan pengguna mengelola informasi profil.
12. **Dashboard Admin:** Menyediakan fitur pengelolaan dan simulasi data kendaraan.

## Cara Menjalankan Aplikasi

1. Clone repository ini atau unduh source code dalam format ZIP.
2. Ekstrak file jika menggunakan format ZIP.
3. Buka folder repository.
4. Masuk ke folder `carfit/`.
5. Jalankan aplikasi dengan membuka file `index.html` menggunakan browser seperti Google Chrome atau Microsoft Edge.
6. Pastikan koneksi internet tersedia apabila aplikasi menggunakan aset atau layanan eksternal.

Aplikasi ini merupakan aplikasi berbasis frontend sehingga tidak memerlukan konfigurasi server backend maupun database.
